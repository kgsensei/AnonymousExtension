Website Update & Extension Whitelist

18/07/26 DMY

Updated the official AnonymousExtension website. Brought the numbers on the homepage up to date and added figure with trackers blocked, technically we can't know exactly how many trackers were blocked but 1 million seems like a nice whole number (and it's probably low by a factor of 10 honestly.) Part of the website update was removing the footer and replacing it with some kgsensei branding, this is the plan for most kgsensei websites currently. Might consider adding a better navigation bar for the website now that the footer is gone though.

Started serious work on the AnonymousExtension whitelist feature, this has been highly requested (basically you can give websites a free pass and AnonymousExtension won't block them.) This allows you to keep using AnonymousExtension for most websites, but not on ones you want to support (via ads) or that get broken because of a false positive.

Also in this update: you can now see your current extension version, the blacklist version, and the number of installed rules.

The version might be hard to read, it's {extension version}x{blacklist version}. So 5.6x7.18.26 means you're running extension version 5.6 and blacklist version 7.18.26

Also investigating ways that to build a "temporary disable" feature which would allow you to turn off AnonymousExtension for a short period (after which it will re-enable itself, so you don't forget.)
